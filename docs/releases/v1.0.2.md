# v1.0.2 — передача в Яндекс Директ при любой установке скилла

Обновление с v1.0.1.

**Что исправлено.** Скилл `yandex-direct-manager` с версии 0.18.0 можно поставить плагином
Claude Code — тогда он называется `/yandex-direct-manager:yandex-direct-manager`, а не
`/yandex-direct-manager`. На шаге передачи в площадки (12В) стратег теперь находит скилл Директа
под любым именем — установленный папкой, плагином или загруженный в Claude Desktop — и в
сообщении показывает то имя, по которому его вызвать. Если скилла Директа нет, стратег скажет
об этом и даст ссылку на установку.

Всё остальное — как в [v1.0.1](v1.0.1.md).

## Обновление

Скачайте новую версию скилла и замените старую (в Claude Desktop — загрузите заново в
«Настройки → Возможности → Скиллы»).
