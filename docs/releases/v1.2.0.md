# v1.2.0 — установка плагином Claude Code

Обновление с v1.1.0.

**Плагин Claude Code.** Стратега теперь можно поставить из маркетплейса ai-hub-open — тогда
новые версии приходят через `/plugin`, без ручной переустановки. В сессии Claude Code:

```
/plugin marketplace add ai-hub-open/claude-plugins
/plugin install marketing-strategist@ai-hub-open
```

Скилл вызывается как `/marketing-strategist:marketing-strategist` или просьбой своими словами.
Чтобы обновления приходили сами: `/plugin` → **Marketplaces** → `ai-hub-open` →
**Enable auto-update**. Если раньше стратег лежал папкой в `~/.claude/skills/`, удалите её —
иначе скилл загрузится дважды.

**Сообщение о новой версии.** В начале разговора стратег сверяет свою версию с GitHub. Если
вышла новая — одним сообщением скажет, что изменилось и как обновиться, и спросит, обновиться
сейчас или продолжить. Без интернета проверка молча пропускается. Сам себя скилл не обновляет —
обновление ставите вы.

Маршрут стратегии и документы на выходе — как в [v1.1.0](v1.1.0.md).

## Обновление

Claude Code с плагином — как выше. Claude Desktop и claude.ai — скачайте новую версию скилла и
замените старую (загрузите заново в «Настройки → Возможности → Скиллы»).
