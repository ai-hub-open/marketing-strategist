# v1.4.0 — стратег говорит с вами, а не с оператором

Обновление с v1.3.4.

**Что изменилось.**

- **Без служебных слов.** Стратег больше не пишет в чат «Подтверди шаг 0», имена файлов, папок и
  служебные значки. Результаты он называет по-человечески: бриф, разбор конкурентов, стратегия,
  медиаплан.
- **Сразу к делу.** Первый вопрос — про материалы и бриф. Горизонт планирования стратег уточняет вместе
  с брифом, а не отдельной остановкой. В Claude Desktop и Claude Code он по-прежнему предложит имя
  рабочей папки и спросит режим работы.
- **Понятные подтверждения.** Каждый вопрос говорит, что будет, если ответить «нет»: например, «Бриф
  верный? Если нет — поправлю его, прежде чем строить стратегию». Обращение — на «вы».

**Что не изменилось.** Этапы стратегии, ключевые точки выбора (гипотезы, УТП, каналы, бюджет) и итоговые
документы — прежние.
