# v1.2.1 — стратег находит скиллы площадок под любым именем

Обновление с v1.2.0.

**Что исправлено.** На шаге передачи в площадки (12В) стратег отдаёт готовую стратегию в скилл
Яндекс Директа и скилл VK Рекламы. Эти скиллы ставят по-разному — папкой, плагином Claude Code
или загрузкой в Claude Desktop — и называются они при этом по-разному: например, плагин VK
вызывается как `/vk-ads-manager:vk-ads-manager`. Теперь стратег находит нужный скилл под любым из
этих имён и показывает в сообщении, как его вызвать. Если скилла площадки нет — скажет об этом и
даст ссылку на установку.

Для Директа так работало с v1.0.2, теперь — и для VK.

Всё остальное — как в [v1.2.0](v1.2.0.md).
