# v1.2.1 — передача в VK Рекламу при любой установке скилла

Обновление с v1.2.0.

**Что исправлено.** Скилл `vk-ads-manager` с версии 0.7.0 можно поставить плагином Claude Code —
тогда он называется `/vk-ads-manager:vk-ads-manager`. На шаге передачи в площадки (12В) стратег
теперь находит скилл VK под любым именем — установленный папкой, плагином или загруженный в
Claude Desktop — так же, как с версии 1.0.2 находит скилл Директа. Если скилла площадки нет,
стратег скажет об этом и даст ссылку на установку.

Всё остальное — как в [v1.2.0](v1.2.0.md).

## Обновление

Claude Code с плагином — `/plugin marketplace update ai-hub-open` и перезапуск сессии. Claude
Desktop и claude.ai — скачайте новую версию скилла и загрузите заново вместо старой.
