# Industry Research — отраслевая аналитика

Используется на Шаге 4. Задача — дать стратегу **карту того, как реально продвигают похожие продукты по разным каналам**: что сработало, какие цифры на старте ожидаемы, какие каналы конкуренты используют.

«Отраслевая» здесь — **узкое пересечение**: «бьюти × B2B SaaS для салонов 5-15 кресел × Москва+СПб», не «всё про маркетинг для бьюти». Чем уже пересечение, тем релевантнее данные.

## Главный принцип

**Не общая информация — а конкретные кейсы с цифрами и указанием каналов.** Статья «Как настроить Директ для бьюти-салона» — это инструкция, не кейс, она НЕ идёт в артефакт. Идёт: «Кейс агентства XYZ: салон в Казани, **Я.Поиск + VK Ads + ретаргет**, CPL снизили с 1 400 до 380 ₽ за 3 месяца, бюджет 200к/мес».

## Вход

1. **Ниша + специфика** из `01_brief.md` — узкое пересечение
2. **Регион** из брифа
3. **Тип спроса** из `02_strategy.md` — для фокусировки поиска кейсов
4. (опц.) **Аналогии** от маркетолога — для экзотических ниш

## Фаза 1 — Определение пересечения и запросов

1. Сформулируй пересечение в одной фразе.
2. Сгенерируй **8-12 узких поисковых запросов** на 4 типа источников:
   - **Кейсы:** «кейс <канал> <ниша>», «<ниша> performance кейс», «<ниша> CAC»
   - **Performance-конференции:** «<ниша> eLama выступление», «<ниша> Yandex Advertising Week», «<ниша> Marketing Day»
   - **Отраслевые статьи:** «<ниша> ppc.world», «<ниша> vc.ru», «<ниша> sostav.ru», «<ниша> blog tinkoff»
   - **Отраслевые отчёты:** «<ниша> рынок отчёт <год>», «<ниша> Mediascope», «<ниша> Data Insight»

Запросы должны быть **узкими**, с явным указанием канала или метрики.

## Фаза 2 — Распознавание экзотичности

Признаки экзотической ниши: срочный спрос, премиум малого объёма, узкий B2B, сезонные товары вне сезона, локальные услуги в малых городах, новые категории.

Для экзотических — механизм **аналогий**:
1. Базовый ресёрч на 1-2 запросах
2. Мало данных (1-2 кейса) → раздел «Аналогии» или спросить маркетолога
3. Вторичный заход по аналогиям, помечая источник «аналогия из X-ниши»

Пример: для эвакуатора в Казани — кейсы такси, сантехников экстренно, межгорода — срочный спрос с похожей экономикой звонка.

## Фаза 3 — Извлечение цифр и каналов

Из источников извлекаем **только то, что можно записать в таблицу**:

| Что искать | Хорошее | Плохое |
|------------|---------|--------|
| CPL/CPA по каналу | «Я.Поиск CPL 380 ₽ при бюджете 200к/мес» | «эффективная цена за лид» |
| CR | «CR клик→лид 4.2% на VK Ads LAL» | «высокая конверсия» |
| Доля бюджета по каналам | «60% Поиск, 25% РСЯ, 15% ретаргет» | «нужен комплексный подход» |
| Срок окупаемости | «3 месяца тестов, окупились на 4-м» | «быстро вышли в плюс» |
| Что не сработало | «Мастер кампаний слил 30% бюджета», «TikTok не дал лидов» | «были сложности» |
| Brand метрики | «За 6 мес рост брендовых запросов +180%» | «выросла узнаваемость» |

Без конкретики — игнорируй, не вытягивай из «общих слов» цифры.

## Аналогии для экзотических ниш

Когда мало кейсов по нише — берём данные из похожей по поведению:

| Ваша ниша | Аналогия | Почему |
|-----------|----------|--------|
| Эвакуатор / экстренный сантехник | Такси, доставка еды | Срочный спрос, звонок, регион-зависимость |
| Премиум-косметология | Премиум-фитнес, частные клиники | Длинный цикл, доверие, отзывы |
| B2B SaaS для салонов | B2B SaaS для ресторанов / автосервисов | Малый бизнес, длинный цикл, владелец = ЛПР |
| Локальная школа танцев | Локальный фитнес, мастерские | Гео-привязка, СЧ-семантика, ретаргет с гео |
| Новый медтех-продукт (нет спроса) | Прорывные SaaS (Notion, Airtable) | Через контент + инфлюенс |

## Гейт

Короткая сводка в чат: какие 2-3 канала с самой сильной доказательной базой в нише + средний CPL по каждому.

В «глубоком» режиме — ждёт «ОК». В «поверхностном» — не ждёт, идём дальше.
