# Buyer Personas — портреты ЦА для cross-channel стратегии

Используется на Шаге 7. Задача — 3-5 портретов покупателя, у каждого явно указано **где живёт цифровым следом** (это критичный вход для Шага 9).

## Главный принцип

**Персона для стратега ≠ персона для брендинга.** Для стратега каждая персона — это **узел в графе «сегмент × канал × запрос»**. Если в персоне нет ответа на «где её ловить» — она бесполезна для выбора каналов.

## Структура одной персоны

```markdown
### Персона N: <короткое название, 3-5 слов>

**Кто это (1 фраза):** возраст / занятие / ситуация / гео.

**JTBD (job to be done):** «Когда [ситуация], я хочу [действие], чтобы [результат]».

**Боли (3-5):** Конкретные раздражители, не «недостатки рынка».

**Возражения (3-5):** «Дорого», «Не сработает у меня», «Уже пробовал…»

**Триггеры покупки:** Что подталкивает к решению именно сейчас.

**⭐ Где живёт цифровым следом (критично для каналов):**
- **Поиск:** какие запросы вводит, в каком поисковике, как часто
- **Соцсети:** какие сети, какие сообщества/группы, насколько активна
- **Мессенджеры:** какие, каких ботов / каналов читает
- **Видео:** YouTube / TikTok / Reels — что смотрит
- **Контентные платформы:** Дзен / vc.ru / Хабр — что читает
- **Профессиональные сообщества:** конференции, чаты, профильные ресурсы
- **Покупает где:** Wildberries / Avito / прямо у бренда / через рекомендации
- **Кому доверяет:** какие лица/издания / блогеры

**Запросы в поиске (5-10):** Дословно. Опечатки, разговорный синтаксис, длинные фразы.

**Месседж:** Главная фраза для объявления.

**На какие УТП откликнется:** связь с гипотезами и UTP-кандидатами.
```

## Пример (мульти-канальный)

### Персона 1: SMM-фрилансер на удалёнке (B2C-like, B2B-инструмент)

**Кто это:** 25-32 года, ведёт 5-15 проектов клиентов, работает дома или в коворкингах, доход 80-200к/мес.

**JTBD:** Когда у меня одновременно 10 контент-планов на неделю, я хочу автогенерить визуалы и заголовки, чтобы успевать за дедлайнами и не выгорать.

**Боли:**
- Постоянная нехватка времени на креативы
- Однотипные посты замыливают глаз клиента
- Дизайнер дорогой, фотобанки скучные

**Возражения:**
- «Мои клиенты заметят что это ИИ»
- «Дорого ещё одно подписочное»
- «Я и сам нагенерю в ChatGPT»

**Триггеры:** новый клиент с большим скоупом, аврал перед запуском.

**⭐ Где живёт цифровым следом:**
- Поиск: гуглит в Яндексе и Google примерно поровну, «сервис для контента», «нейросеть для smm», «генерация постов»
- Соцсети: подписана на 50+ Telegram-каналов про SMM, читает «Тёмная сторона», «Hooglin», «SMM без воды»
- Мессенджеры: 90% коммуникации в Telegram, общается с коллегами в нескольких профессиональных чатах
- Видео: YouTube — обзоры инструментов, иногда TikTok — короткие туториалы
- Контент: vc.ru (раздел Marketing), Дзен — редко
- Профсообщества: чаты в Telegram, иногда конференции (Suzdal SMM)
- Покупает где: подписки — прямо у сервисов, через триал
- Кому доверяет: коллеги-фрилансеры, ведущие профессиональных Telegram-каналов

**Запросы:**
```
сервис для контента в соцсетях
автоматизация смм
программа для постов в инсту
сервис генерации картинок для смм
ai контент для соцсетей
автогенерация постов
```

**Месседж:** «Сгенерируй неделю постов за вечер. ИИ, который пишет в стиле твоего клиента».

**На какие УТП откликнется:** «Кастомизация под стиль клиента» (Гип.1), «Тариф для фрилансера» (Гип.4)

→ **Маппинг на каналы:** Я.Поиск (5/5) + Telegram-посевы в проф-каналах (4/5) + YouTube-обзоры (3/5)

## Сколько персон

**3-5 оптимально.** Если 1 — нет тестов гипотез. Если 7+ — фрагментация, не запустить столько связок на тесте.

## Как генерить персон автоматически

На Шаге 7, на основе материалов Шагов 1-6:

1. **Раскладываем по осям сегментации** (см. `hypothesis-builder.md`).
2. **Каждая выбранная гипотеза → 1-2 персоны.** Гипотеза = угол, персона = конкретный человек, на которого этот угол работает.
3. **Привязываем к УТП-кандидатам** из черновика (финал на Шаге 8).
4. **Проверка реальностью:** покажи маркетологу — «Эти люди реально приходят? Кого не хватает?»

## Источники для «где живёт цифровым следом»

- **`industry_research.json`** — каналы конкурентов (значит ЦА там есть)
- **`05_competitor_analysis.md`** — где сидят конкуренты в соцсетях/чатах
- **Поиск отзывов и форумов** (например, `WebSearch`) — где обсуждают эту нишу
- **Поиск «ниша + Telegram»** — какие профильные каналы
- **Поиск «ниша + конференции»** — где собирается оффлайн
- **Гипотезы маркетолога** — но не доверять слепо, валидировать

**Если поиска в интернете в среде нет** — остаются первые два источника и гипотезы маркетолога. Тогда блок «где живёт цифровым следом» строится на каналах конкурентов и словах клиента: помечай его `source: гипотеза` целиком и ставь пометку о пропуске в `07_personas.md`. Профильные Telegram-каналы и конференции не выдумывай — пустое поле честнее выдуманного, потому что по нему потом планируют размещения.

## Защита от типовых ошибок

**Ошибка 1:** «Персоны без указания каналов».
- Решение: блок «Где живёт цифровым следом» — обязательное поле, не опциональное.

**Ошибка 2:** «3 одинаковые персоны с разным возрастом».
- Решение: разные оси сегментации = разные триггеры покупки = разные персоны. Просто возраст — не персона.

**Ошибка 3:** «Персона = собирательный образ».
- Решение: одна персона = конкретный реальный сегмент. Не «портрет российского пользователя 25-45».

**Ошибка 4:** «Запросы выдуманы / общие».
- Решение: 5-10 дословных запросов, как человек реально написал бы в поиске.

## Гейт

Покажи сводную таблицу персон × каналов. «Эти 4 персоны? Каналы покрывают?»

В «глубоком» режиме — ждёт «ОК».
