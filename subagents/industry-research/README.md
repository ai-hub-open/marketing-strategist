# industry-research (субагент)

Часть набора **marketing-strategist v2**. Это не самостоятельный инструмент —
форк-субагент Шага 4 (отраслевая аналитика), который вызывает оркестратор.

- Запускается по команде `/industry-research <slug> "<ниша>" "<регион>"`
  (обычно её даёт сам оркестратор, не человек).
- Работает в изолированном контексте (`context: fork`), возвращает только сводку.
- Reference вложен в пакет (`references/industry-research.md`).

Ставить вместе с `marketing-strategist.zip`. Подробности — в INSTALL главного пакета.
