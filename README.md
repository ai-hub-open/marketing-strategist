# Маркетинг-стратег

Скилл готовит рекламную стратегию до настройки кампаний: ИИ-агент разбирает продукт и сайт, исследует отрасль и конкурентов, формирует гипотезы, портреты покупателей и УТП, выбирает площадки, распределяет бюджет по фазам и задаёт KPI.

На выходе — отчёт, медиаплан, одностраничное резюме и рабочие файлы всех этапов. Скилл не подключается к рекламным кабинетам, не запускает рекламу и не тратит бюджет.

## На чём стоит маршрут

Стратегию можно собрать разговором с любой языковой моделью. Разница в том, что разговор каждый раз идёт по-новому, а цифры в нём меняются под формулировку вопроса. Здесь маршрут зафиксирован, и у каждого решения есть критерий, записанный до начала работы:

- **УТП** проверяется по пяти критериям Котлера, а не по вкусу — кандидаты отсеиваются по одной и той же шкале.
- **Площадки** оцениваются по шести критериям с баллами; в финал выходят три с приоритетами. Это ответ на вопрос рекламодателя «почему именно эти каналы», который выдерживает уточнения.
- **Бюджет** раскладывается по трём фазам — тест, оптимизация, масштаб, — а KPI получают правила «сокращать / усиливать / отключать», а не остаются числом в отчёте.
- **Отраслевые ориентиры** — стоимость привлечения и ценность покупателя — собираются до выбора каналов, поэтому раскладка опирается на нишу, а не на общие соображения.

Методики этапов лежат в [`references/`](references/) — одиннадцать справочников, по которым агент работает. Их видно целиком до установки: маршрут открыт для чтения и разбора, включая формулы, пороги и шкалы оценки.

Отдельно про честность данных: чего нет в источниках, агент помечает как непроверенное. Пустые места в стратегии видно сразу, и это осознанное свойство, а не недоработка.

## Как проходит работа

Маршрут состоит из 13 этапов и делится на три части.

**Сбор фактов.** Агент читает сайт, извлекает данные из материалов рекламодателя и добирает недостающее вопросами. Дальше — отраслевые ориентиры и разбор конкурентов с матрицей «конкурент × канал»: где борьба плотная, а где есть свободное место. Тяжёлые исследования вынесены в отдельные потоки, чтобы объём выдачи не заполнял основной разговор.

**Решения.** Гипотезы запуска, портреты покупателей, УТП, выбор площадок, раскладка бюджета и KPI. Это узловые точки: агент предлагает варианты с обоснованием, выбор остаётся за маркетологом. В пошаговом режиме подтверждение требуется на каждом этапе, в быстром — только на этих развилках.

**Документы.** Отчёт, медиаплан и резюме собираются из накопленных файлов, а не пишутся заново, поэтому итог сходится с промежуточными материалами.

Каждый этап сохраняет результат отдельным файлом, состояние хранится в рабочей папке. К стратегии можно вернуться в новой сессии с того же места, а любой шаг — перечитать и оспорить.

## Результат

- `marketing_strategy.docx` — стратегия по продукту, аудитории, конкурентам, площадкам, бюджету и KPI;
- `media_plan.xlsx` — медиаплан по каналам, фазам и неделям;
- `strategy_summary.pdf` — резюме на страницу для согласования;
- рабочие файлы этапов: бриф, исследования, гипотезы, портреты покупателей, УТП, выбор каналов, бюджет, KPI.

Если библиотек для DOCX, XLSX или PDF нет, генераторы сохраняют те же материалы в Markdown и CSV.

## Что входит в пакет

| Путь | Содержимое |
|---|---|
| [`SKILL.md`](SKILL.md) | маршрут работы |
| [`references/`](references/) | 11 методических справочников по этапам |
| [`subagents/`](subagents/) | исследовательские потоки для отрасли и конкурентов |
| [`scripts/`](scripts/) | генераторы отчёта, медиаплана и резюме |

Исследовательские потоки — `industry-research` и `competitor-research` — запускаются отдельно, чтобы разбор десятков источников не вытеснял основной разговор. Если среда их не поддерживает, скилл проходит те же этапы сам по тем же справочникам.

## Границы

- Скилл не создаёт объявления и креативы и не подключается к API рекламных площадок.
- Кампании он не активирует и бюджет не расходует — это остаётся за человеком.
- Передача материалов автоматизирована для пакетов Яндекс Директа и ВК Рекламы; для остальных площадок используется итоговый отчёт.
- Данные без источника помечаются как непроверенные и требуют проверки до защиты стратегии.
- Рабочий язык — русский.

## Установка

Подробная инструкция — в [`INSTALL.md`](INSTALL.md).

### Claude Cowork

Среда принимает скиллы ZIP-архивами; готовые архивы к релизу не прикладываются. Папки упаковываются самостоятельно и загружаются через **Settings → Skills → Upload**:

1. корень репозитория без папки `subagents/` — основной скилл;
2. `subagents/industry-research/` — исследование отрасли;
3. `subagents/competitor-research/` — исследование конкурентов.

### Claude Code

```bash
# из папки, куда клонирован репозиторий
cp -r marketing-strategist ~/.claude/skills/
cp -r marketing-strategist/subagents/industry-research ~/.claude/skills/
cp -r marketing-strategist/subagents/competitor-research ~/.claude/skills/
rm -rf ~/.claude/skills/marketing-strategist/subagents
```

После перезапуска агента достаточно попросить его подготовить маркетинговую стратегию, назвав продукт и адрес сайта.

## Необязательные зависимости

```bash
pip install python-docx openpyxl reportlab
```

Без них скилл продолжит работу и сохранит документы в Markdown и CSV.
