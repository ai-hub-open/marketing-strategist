# Маркетинг-стратег

Скилл для подготовки рекламной стратегии до настройки кампаний. ИИ-агент разбирает продукт и сайт, исследует отрасль и конкурентов, собирает гипотезы, портреты покупателей и УТП, выбирает рекламные площадки, распределяет бюджет по фазам и задаёт KPI.

На выходе — основной отчёт, медиаплан, одностраничное саммари и рабочие материалы всех этапов. Скилл не подключается к рекламным кабинетам, не запускает рекламу и не тратит бюджет.

## Как проходит работа

Работа идёт по шагам 0–12. После каждого шага агент сохраняет результат в файл и показывает короткую сводку. В пошаговом режиме он ждёт подтверждения перед продолжением; в быстром — останавливается только на принципиальных развилках.

1. **Настройка.** Создаёт рабочую папку кампании и файл состояния.
2. **Материалы клиента.** Извлекает факты из брифа, презентации, переписки и результатов прошлых кампаний.
3. **Бриф продукта.** Читает сайт и собирает недостающие данные: регион, цель, юнит-экономику, бюджет, сезонность и исключения.
4. **Стратегический слой.** Фиксирует тип спроса, воронку, цели на 1, 3 и 6 месяцев и явные ограничения.
5. **Отраслевая аналитика.** Ищет ориентиры по CAC и LTV, рабочие площадки и типовые ошибки в нише.
6. **Конкуренты.** Собирает матрицу «конкурент × канал» и показывает, где борьба плотная, а где есть свободное место.
7. **Гипотезы запуска.** Формирует 5–8 гипотез «кому → что обещаем → где проверяем»; вы выбираете 2–4 для теста.
8. **Портреты покупателей.** Описывает 3–5 сегментов и их цифровой след.
9. **УТП.** Проверяет кандидатов по пяти критериям Котлера; вы выбираете основное и резервное УТП.
10. **Выбор площадок.** Оценивает каналы по шести критериям и предлагает три приоритетных варианта с обоснованием.
11. **Бюджет.** Распределяет деньги между тестом, оптимизацией и масштабированием.
12. **KPI и мониторинг.** Задаёт целевые показатели и правила «сокращать / усиливать / отключать».
13. **Отчёт и передача.** Собирает итоговые документы и план передачи в пакет выбранной рекламной системы.

Состояние хранится в рабочей папке, поэтому к стратегии можно вернуться в новой сессии с того же шага.

## Результат

- `marketing_strategy.docx` — стратегия по продукту, аудитории, конкурентам, площадкам, бюджету и KPI;
- `media_plan.xlsx` — медиаплан по каналам, фазам и неделям;
- `strategy_summary.pdf` — одностраничное саммари для согласования;
- файлы брифа, исследований, гипотез, портретов покупателей, УТП, выбора каналов, бюджета и KPI.

Если библиотек для DOCX, XLSX или PDF нет, генераторы сохраняют текстовые версии в Markdown и CSV.

## Что входит в пакет

| Путь | Содержимое |
|---|---|
| `marketing-strategist/SKILL.md` | основной маршрут работы |
| `marketing-strategist/references/` | 11 методических справочников по этапам |
| `marketing-strategist/subagents/` | отдельные исследовательские потоки для отрасли и конкурентов |
| `marketing-strategist/scripts/` | генераторы стратегии, медиаплана и саммари |
| `dist/` | готовые архивы для установки |

### Исследовательские потоки

- `industry-research` — собирает отраслевые ориентиры, каналы конкурентов и рискованные практики;
- `competitor-research` — читает сайты конкурентов, разбирает УТП и цены, строит матрицу каналов.

Если среда не поддерживает отдельные рабочие потоки, основной скилл выполняет те же шаги самостоятельно по тем же справочникам.

### Генераторы документов

## Что делает агент, а что остаётся человеку

**Агент:**

- читает сайт и собирает бриф;
- исследует отрасль и конкурентов;
- формирует гипотезы, портреты покупателей и кандидаты УТП;
- оценивает площадки, распределяет бюджет и собирает KPI;
- формирует итоговые документы и план передачи.

**Человек:**

- дополняет бриф недостающими фактами;
- выбирает гипотезы, УТП и три приоритетные площадки;
- подтверждает доли бюджета и финальную сборку документов;
- запускает кампании в рекламных кабинетах.

## Ограничения

- Скилл не создаёт объявления и финальные креативы для рекламных кабинетов.
- Он не подключается к API рекламных площадок и не активирует кампании.
- Данные без источника помечаются как непроверенные.
- Передача материалов автоматизирована только для пакетов Яндекс Директа и ВК Рекламы; для других площадок используется итоговый отчёт.
- Скилл работает на русском языке.

## Установка

Подробная инструкция находится в [`marketing-strategist/INSTALL.md`](marketing-strategist/INSTALL.md).

### Claude Cowork

Загрузите архивы из `dist/` через **Settings → Skills → Upload**:

1. `marketing-strategist.zip` — основной скилл;
2. `industry-research.zip` — исследование отрасли;
3. `competitor-research.zip` — исследование конкурентов.

### Claude Code

```bash
unzip dist/marketing-strategist.zip -d ~/.claude/skills/
unzip dist/industry-research.zip -d ~/.claude/skills/
unzip dist/competitor-research.zip -d ~/.claude/skills/
```

Либо скопируйте папку `marketing-strategist/` целиком в `~/.claude/skills/`.

## Необязательные зависимости

```bash
pip install python-docx openpyxl reportlab
```

Без них скилл продолжит работу и сохранит документы в Markdown и CSV.
